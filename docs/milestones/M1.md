## Important Decisions

M1 was not a clean-sheet rewrite.

The frozen v1 implementation remained as a compatibility oracle while behavior
was progressively extracted into components.

The following control-loop semantics remained non-negotiable:

- Generator != Verifier
- deterministic verification first
- independent review
- risk aggregation
- bounded execution
- AUTO_FINISHED / HUMAN_REQUIRED

## Deviation / Implementation Strategy

The Master Plan said “refactor”; the concrete implementation strategy became:

`preserve legacy -> characterize -> extract -> compare`

rather than a big-bang rewrite.
