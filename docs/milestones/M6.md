## Important Decisions

### Exact Computational Identity

A task fingerprint is an exact identity, not semantic similarity.

Low exact-task hit rate was NOT solved by pretending similar natural-language
tasks were identical.

Reuse was decomposed into safer lower-level artifacts such as repository maps
and stable prompt prefixes.

### Dirty Working Tree Boundary

A HEAD-SHA cache identity is sound only when filesystem content corresponds to
that identity.

Shared cross-run cache was therefore disabled for dirty-capable dry-run paths.

### Stale Cache Fails Closed

A stale/corrupt logical cache entry raises integrity failure before silent
fallback.

### Semantic Cache Deferred

Fuzzy/semantic task equivalence was explicitly not accepted in M6.
