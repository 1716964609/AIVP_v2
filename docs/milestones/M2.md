## Important Decisions

### State is not Cache

State answers:

> Where has this run safely progressed?

Cache answers:

> Can a previous computation be safely reused?

These remain distinct subsystems.

### Resume is also Cost Engineering

A completed expensive model step should not be repeated merely because the
process died.

### Integrity Fails Closed

Corrupted/stale checkpoint or artifact identity must not silently continue.
