## Important Decisions

### M7 Is a Measuring Instrument

M7 observes, measures, grades, compares, and preserves evidence.

It does not introduce M8 routing behavior.

### Benchmark Freeze Boundary

Case expectations were calibrated during shakedown.

After corpus freeze, benchmark expectations were not changed in response to
formal-run outcomes.

### Execution Attempt != Verification Round

Live shakedown exposed that one durable execution attempt may contain multiple
verification rounds.

Verification artifact and step identities therefore became
`attempt x verification_round` aware.

### Model Output Failure Is a Terminalized Failure

Malformed structured model output is normalized to a typed model-output
failure and safely terminalized as HUMAN_REQUIRED rather than escaping the
Harness.

### Missing Economics Is Not Zero

The formal benchmark contains one nominal `$0.00` USD-cost sample from the
scripted `budget-exhaustion` case.

It is not treated as live-provider billing evidence.

Live-provider USD-cost coverage is therefore unavailable at the M7 boundary.

M7 does not infer subscription billing or claim a dollar-cost improvement.

## Negative Evidence

M7 preserved unsuccessful and interrupted runs rather than rewriting history.

The first formal run exposed an external Codex usage-limit failure.

A later run was manually interrupted during Claude review.

Both remain evidence, but neither is used as the successful formal benchmark.
